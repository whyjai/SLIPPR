# Fonts for server-rendered images

Static-weight TTF instances of **Geist** and **Geist Mono** (by Vercel), used by
`next/og` (Satori) in `/api/og/daily-slip`. Satori can't read the WOFF2 /
variable fonts that `next/font` serves, so these are pre-instanced copies.
